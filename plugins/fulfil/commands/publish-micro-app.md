# Publish Micro App

1. Confirm which app and which version. If unclear, list the app's versions and
   show the user which is currently live.
2. Say what goes live and what it replaces — this changes what everyone in the
   workspace sees. Get confirmation.
3. Publish.
4. Read the app back to confirm the live version, and report the previous one so
   a rollback target is on the record.
