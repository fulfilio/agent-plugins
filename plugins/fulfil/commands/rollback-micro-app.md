# Rollback Micro App

1. Show the user the published versions and which is live now.
2. Roll back to the chosen version.
3. Read the app back to confirm the live version — do not assume the call took
   effect.
4. If a bug caused this, say what the local source needs so the repo does not
   drift from what is live.
